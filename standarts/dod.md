# Definition of Done (DoD) та Перелік перевірок

Кожна фіча/модуль вважається завершеною, якщо виконуються наступні умови:

## 1. Архітектура та Код
- [ ] Жодних `any` у коді (Strict TypeScript).
- [ ] Бізнес-логіка не містить блоків `try/catch`. Помилки викидаються через кастомний `AppError` і перехоплюються глобальним обробником Fastify.
- [ ] Взаємодія між модулями відбувається виключно на рівні Service.
- [ ] Наскрізний `TraceID` доступний через `AsyncLocalStorage` (хук `onRequest`), без протягування через параметри функцій.

## 2. Дані та Транзакції
- [ ] Усі мутуючі операції (створення замовлення + списання) інкапсульовані всередині `prisma.$transaction`.
- [ ] Запобігання Race Conditions реалізовано на рівні БД атомарними операціями (`decrement`, `gte`).
- [ ] Ідемпотентність: обробляється заголовок `Idempotency-Key` (перевірка дублікатів у транзакції).

## 3. Інфраструктура та CI
- [ ] Проєкт проходить `npm run lint` та `npm run build` (без помилок компіляції).
- [ ] Відсутність мертвого коду, кирилиці в логах та закоментованих блоків.
- [ ] Тести (Smoke / Unit / E2E) проходять успішно (`npm run test`).
- [ ] При старті застосунку обов'язково відпрацьовує Fail-fast перевірка БД.
